LAN Controller

LAN 模式操作流程

  1. 两台电脑连接同一个局域网 / Wi-Fi。
  2. 电脑 B 启动 LTE-Modem-Node-Agent.exe。
  3. 确认电脑 B 的局域网 IPv4，并与启动向导中的 Modem IP 一致。
  4. 确认 AP-Modem / Modem-eNB / Management 端口与 token 两端一致。
  5. 点击“测试连接”，确认 Agent、Management 与两条协议 Socket 均 READY。
  6. 状态正常后再进行 Attach；Modem→eNB 会在真实协议消息发生时建立 TCP。

    推荐方式直接点击右侧按钮：由当前后端进程调用独立 StandaloneSrtpModule，不会额外弹出 PowerShell/CMD 窗口。

    尚未运行点击后结果直接显示在本页，同时由后端保存 JSON 证据；不会启动 LTE Attach，也不会读取 Scenario/FaultConfig。
    准确性验证层次四层证据互相独立：标准答案、协议状态、参考实现、真实网络链路。
    ① RFC 标准向量待检查RFC 3711 / RFC 2202 known-answer vectors
    ② Core 状态与边界待检查ROC / Replay / Header / 并发 / fuzz
    ③ 参考实现差分可选安装 pylibsrtp 后与 libSRTP 双向对照
    ④ 真实 UDP 端到端待运行Sender → protect → UDP → verify/unprotect
    ① Core 健康检查验证 SRTP Core 状态机、Replay/ROC 和 RFC 标准向量；不执行 UDP 场景。
    ② 端到端链路验证Sender → SRTP Core → UDP → Receiver；正常与异常场景统一从这里运行。
    Security Core 尚未检查Core 健康检查用于确认协议实现；端到端结果由所选 UDP 场景单独验证。
    正常链路预期：单包经 SRTP 保护、真实 UDP 传输后被接收端接受。
